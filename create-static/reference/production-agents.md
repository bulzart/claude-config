# Production agents: one video per agent

In a /create-static run each video is produced by its **own background agent**, so no video waits behind another's images or
CapCut build. The work is split:
- **this session** plans and prepares (command A6s–A9s; skills `cs-sound` for each video's narration and bed, and `cs-produce` for the spawn
  and the reports);
- **each agent** runs its one video from the stills to the CapCut project and the record (S3, S4, X10; skills `cs-images`, `cs-edit`,
  `cs-record`, invoked from its contract).

At most 5 agents run at once, none overlapping.
