How this page is filled

An agent (or the main session) records a flag with atp.py caught-flag add the moment Higgsfield refuses, blocks, withholds or reroutes something. The script gathers what the run already knows: the video, the attempt, the request's prompt and parameters, every input with its file and type, the reference and the source segment, the job and its ledger row. The agent adds the judgement: Higgsfield's reply, the suspected trigger, which input, which words of the prompt and which part of a video, and a few grouping tags. Nothing in a run reads this page.

Statusopen: not cleared yet · cleared: a changed request was accepted · persistent: the flag stayed, the video was planned another way or reported
EvidenceE: seen in the response or the files · I: an inference, not confirmed by Higgsfield
