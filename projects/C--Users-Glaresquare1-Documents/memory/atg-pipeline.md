On 2026-10-11 the user asked for a new pipeline `/analyze-then-generate` with a new Analyze sub-mode `viral-browser` (next to Recreate and Create) and a build prompt file like `analyze-then-pick.txt`. They named `analyze-stack-build-prompt.txt` as the base, but that file is the old `/analyze-stack` spec (Modes 1-3); the Recreate/Create structure they described is `analyze-then-pick.txt`, so the fork was made from the ATP library (snapshot 2026-10-10 14:04) and from that build prompt. `/analyze-then-pick` itself was not changed.

**What exists**
- Command `~/.claude/commands/analyze-then-generate.md` (contract items 23-25, steps V1-V9 after A10), library `~/.claude/analyze-then-generate/` (own toolkit `scripts/atg.py`, the ledger copied with CE-001..CE-029 and extended, `learning-log.md`, all references and model guides), the playbook `reference/viral-browser.md`, config `viral_browser` in `config.json` (the former gate numbers are in `viral_browser.rules_of_thumb`: guidance for the agent, read by no script), build prompt `Documents/prompts/analyze-then-generate.txt` (generated by a script from `analyze-then-pick.txt` plus the Viral-Browser block; same CRLF prose style; regenerate after every change).
- **THE RULE (user, 2026-10-12, every mode): scripts gather, extract, record, tabulate and calculate; agents decide and record why** (see [[scripts-gather-agents-decide]]). In atg.py nothing ranks, gates, caps, labels or refuses on content: `candidates` is a ledger (add/list/show/set/rate/summary/table; the table sets ratings, a plain weighted sum, economics per market and an evidence cell side by side), `niches` records the agents' vocabulary (add/map/merge/audit/list/propose), `evidence` (add/retract/list --counts), `spec` (facts side by side, `spec judge` records the agent's status/value/reason, `gaps`), `photo` (page reader, HEAD probe, coverage table), `viral-stats` (distributions and label tables, no dominance), `econ` (arithmetic, per market), `audio-context` / `audio-profile` (numbers, no music-bed or lyric labels), `qc`, `sync-check`, `scale`, `conform --dry-run`, `finalize`, `restore-audio`, `ledger begin` (records, reports `conflicts`), `model-menu` (no quick picks), `inventory` (no name hints).
- Viral-Browser flow: asks market (US/EU/global) and price range (plus selling model, Chrome yes/no; exclusions come from the user's message only); per-reference viral cards (product layer apart from mechanism layer; a one-line `Facts:` JSON whose `category` is a niche label the agents reconcile into a run-level niche vocabulary; Facts also carry `voice_type`, `shots_seen`, `price_tier` only when a price shows, `creator_group` assigned by the main session; **no niche, product or category name in any script or config, user rule 2026-10-11**); `viral-stats`; mechanism map, essence, fit profile; 12-20 specific candidates from five sources; the main session applies the pool-balance and dominant-niche rules of thumb and writes the bias log in `30-research/ranking.md`; a fresh niche-audit agent; up to 3 research agents (origin-blind dossiers, evidence rows graded A-D with signal and independence; economics per market); a fresh blind scoring agent (`candidates rate`; the main session never scores); a red team; the MAIN session applies the six gates by reading `candidates table`, writes `ranking.md`, records picks with `--pick-rank --by --reason`; one backfill wave; three picks + blueprints in `RUN/deliverables/`, each with a **reference pack** (user, 2026-10-12: official or verified size/weight/material/texture/usage plus multi-angle photos): sourced facts with `T spec`, **image URL links only, nothing downloaded** (user correction, see [[atg-photo-links-only]]), one agent per pick (`viral-browser.md` 9.1, 13.7); optional continue-to-Create on the user's yes. Nothing is generated.
- **Create is a blend here (user, 2026-10-11):** it understands the references (craft sheet, audience, trend) AND the product (`30-assets/product-insights.md`) and blends both; families are evidence, never a menu; every seed names its blend and passes the blend test and the template-lock test (`creative-direction.md` 5.0b). **Since 2026-10-12 Create also runs the Viral-Browser mining** on the references (cards, `viral-stats --no-niche` -> `corpus-profile.*`, mechanism map, trend pass, blend matrix, virality rationale per video, `deliverables/blends.md`; `viral-browser.md` section 14). Not ported to `/analyze-then-pick`.
- **Audio context in every analysis mode (user, 2026-10-12):** the agents transcribe and understand the references' audio in Viral-Browser, Create and Recreate (Recreate: context only; the reference sent to Higgsfield stays silent). faster-whisper (open source Whisper, `small` cached, CPU, offline) verified on mp3; `T audio-context --profile --second-pass` writes `20-analysis/audio-context.md` (transcripts, numbers, no labels), every card has `Audio context:`, `Said:`, `Words and sound together:` lines, `--check --cards` is a completeness check that writes nothing. A bigger model (medium) is optional and not installed.
- Ledger modes/causes for picks: `--mode analyze-viral-browser`, causes research / scoring / bias / evidence.
