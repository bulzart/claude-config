Built 2026-10-20 (commits in `~/.claude` from bd7d840 on; Loupe commits bc320a7, 6323b5a and the docs commit after them). `/analyze-with-loupe` = the router `commands/analyze-with-loupe.md` + 24 skills `skills/awl-*` (20 at the copy) + the library `~/.claude/analyze-with-loupe/` (README, learning log, sectioned references, model guides, Higgsfield notes, `scripts/awl.py`, `scripts/docs_tool.py`, `scripts/check_all.py`, `tests/`) + the build prompt `Documents/prompts/analyze-with-loupe.txt`. Home variable `AWL_HOME`, path alias `AWL`, env `AWL_TRANSCRIBE_STUB`, `AWL_KEEPER_SYNC_WAIT`, `AWL_TEST_*`. Run it as `/analyze-with-loupe analyze <refs> assets <assets…> | edit <videos…> | resume <run>`; runs live in `analyze-with-loupe/runs/`.

**What it keeps:** everything /analyze-then-pick does (every mode, the audio-ingest question of contract item 24, Loupe at run start, flags, qc-consult once per video; since 2026-10-28 X2 asks the judge for a prompt template, `T prompt-template`, instead of plan-hints, see [[awl-judge-template]]; QC fixes has a third choice `off`, see [[no-qc-regeneration-user-reviews-end]]). The same golden-path rehearsal (`tests/rehearsal.py`; 118 steps on both pipelines at the copy, 208 with the two Free paths: Recreate, Create, Free with references, Free requirement only, and Edit; 221 on 2026-11-05).

**The Free sub-mode (user 2026-10-20):** the third Analyze sub-mode: the user's own requirement (kept verbatim in `00-inventory/requirement.md`) decides what the videos achieve and how, with references analysed first or from the requirement and the assets alone; `awl-free-plan` (A6f) writes the free plan with [U]/[E]/[I] lines, lists the past misses that touch it (`T qc-brief`), is confirmed once, and gives each video a kind (`videos_kind`: recreate | create) that selects the branch of every per-video step; the hard rules, the model's official prompting, the QC stack and Loupe stay. The QC-fixes choice (item 27) is asked in every Analyze sub-mode.

**The Static sub-mode (user 2026-11-05, contract item 36):** the fourth Analyze sub-mode: narrated still-image videos in the references' craft on a new subject (characters in the assets decide the kind: story, facts or biography, kids' storytelling). No Higgsfield and no Loupe at all. References at exactly 1 fps plus Whisper; A6s (`awl-static-plan`) gives a subject pool and three voice samples at one stop; S2 `awl-static-sound` (Qwen3-TTS 1.7B: design → clone, one voice per run; ACE-Step 1.5 bed only when needed), S3 `awl-static-images` (OpenAI Images API `gpt-image-2.5-sunburst`, key only in `OPENAI_API_KEY`; or a prompts file and the user's folder), S4 `awl-static-edit` (`T slideshow` render + CapCut project, captions by `capcut import-srt`). Qwen and ACE-Step run on another PC (the "Static PC"; `AWL_TTS_PYTHON`, `AWL_MUSIC_PYTHON`, `AWL_MUSIC_ROOT`; setup in reference/static §9); `T static check` reports each part. The CapCut project is the final (the user exports it; no tool can): its canvas and the images follow the format the user picks at A5 with the count (`T static formats` facts, the references' best fit first and marked Recommended, then options; `T static format` → `state.json → static.format`; 9:16 at 1080 = 1216×2160 images, sharp through the 12 % zoom). Strong lines (`"strong": true` + `delivery`) come from VoiceDesign with the picked sample's seed, only at the references' peaks, measured (pitch, timbre) against the cloned lines and redone or cloned when apart. The same day Recreate got the whole-source rule ([[one-generation-up-to-15s]]).

**What it changes (the report `Documents/prompts/coupling-report-2026-10-20.md` lists each with its evidence):** contract item 25 scripts gather, agents decide (`sync-check`, `ledger begin`, `conform`, `scale`, `qc`, `audio-profile`, the OCR spans, `restore-audio`, `finalize`, `model-menu` return numbers and facts, never a verdict, label or refusal; the rules of thumb sit in the references); item 27 QC fixes `ask` | `auto` (`state.json → qc_fixes`); item 26 pilot first; produce items 28–30 (stalled agent, request freeze with `lint-run`, planner contract); `T uploads set|show|merge` (one schema), `T contract --run RUN`, `T frames --grid`, `T hf-put --capture <id>`; the preview is the 720×1280 burn; no faded-product clause. **The prompts of the two takes (user 2026-10-20):** a sample marked `prompts` keeps in Loupe the wrong take's and the corrected take's prompts with the admin's note; `T sample-prompts --id S12 --run RUN` writes both whole to `RUN/40-briefs/samples/S12-prompts.md` for a sample the agent judged relevant (X2: an applied hint, at most two per video; QC: a diagnosed cause); `plan-hints` and `qc-consult` print a `prompts_rule`; the agent judges what changed, nothing is diffed in code, nothing pasted ([[loupe-web-app]]).

**Shared infrastructure changed for it (the old pipelines keep working, their tests green):** Loupe `core.LIBS` has `awl` (`AWL_HOME`); consult answers carry `title`, `model`, `run`, `video`, `t_wrong`, `kinds`; every keeper field is cut at a sentence end; honest fetch reasons; `needs_unmet` only unmet; `held_back_why`; the keeper process group is ended on timeout and the lock is acquired with a timeout (`mode: busy`); `GET /api/qc/keeper/state` (qc key); `GET /api/misses/suggest-kinds` + the form button; the composite's legend and zoom rule. Hooks: the three hooks list the third library; `media_upload` answers are captured (the reminder names `awl.py hf-put --capture` only for a run of this library).
