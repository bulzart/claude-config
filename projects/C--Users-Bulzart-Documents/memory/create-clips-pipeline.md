- **The chunk reporter (user 2026-11-13, replaces Haiku scan agents):** after a chunk is processed the watcher spawns a separate headless `claude -p` session (Haiku 5.5 `claude-haiku-5-5`, `--effort high` because the user never wants Haiku below high, `--tools Read`, `--strict-mcp-config`, `--setting-sources project` so the user's hooks (autocommit) and settings are left out, `--no-session-persistence`, stream-json so the files it REALLY opened are counted) that reads the sheets, audio numbers, transcript, chat and writes `10-media/Cnnnn/report.json` + `report.md`. **A reporter, never a decider** (`reference/reporter.md`): no verdict, no label like "ace", no name corrected/identified, nothing ranked or kept; unknown fields are dropped by a whitelist. Config `report` (parallel 2, timeout 420 s, 2 attempts); `cc.py report` makes/redoes reports; real claude.exe must be first on PATH (see [[pc-pipeline-tooling]]). Measured: ~35-65 s and ~$0.006-0.01 for a 30 s test chunk. No `model` argument to any agent anywhere: the user's /model decides; the command's agents read the reports and decide.
- **Command** `/create-clips <run> [mode=streamer|game] [game=...]` (`~/.claude/commands/create-clips.md` router, 12 `cc-*` skills, `reference/` and `reference/games/`). **The user picks the mode at the very start** (AskUserQuestion in `cc-start`; `mode=` skips it; never guessed).
