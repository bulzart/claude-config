User 2026-11-20 (master narration brief, implemented as tag static-studio-narration-1): the narrator is an editorial choice per video for its locked treatment (a series may share a voice on purpose); every TTS request takes voice, model and settings from `60-voice/video-NN/voice-lock.json` (no command-line override, no global `--delivery` prefix; a change is `voice-pick --replace --reason`). Stability is chosen for the narrator, never to move pace: Eleven v4 applies no speed setting (official docs), so pace is measured and the script sized to it. Tags only where the writing can't carry a change, each explained under "Delivery and tags" (UPDATED 2026-11-22, brief #4 Part 7: every narration carries purposeful v4 delivery and/or pause cues where moments call for them; no quota, never decoration, never a cover for unclear writing; a script with none is refused by plan-check unless `tags_exception` records the reason and the user's own approval; never re-record only to add tags). Every planned pause says what it is for and the cold reader is shown the holds: silence never pads an underwritten script, but there is no universal maximum (since 2026-11-21 a pause is a whole-silence proposal decided on the recorded voice and the picture: [[create-video-held-silences]]). Parts follow the beats (about 3,500 characters, a guideline). Every line must be heard (number-normalised alignment, a Whisper medium re-hearing of a missed line) and no tag read aloud. In CapCut the narration is the edit plan's file at 0 s, speed 1, untrimmed. Credits: ElevenLabs' model rate plus the live balance, every billed request in the run's ledger; Voice Design priced first.

**Why:** the user wants a narrator that feels human ("expressive but not theatrical", "faster isn't necessarily better"); the audit found controls that did nothing or could slip (speed, the global tag prefix, 8,000-character parts split mid-beat, silence padding, an unchecked CapCut narration track).

**How to apply:** keep these when editing static-studio. Never add a speed control, a global tag or a fixed stability. Paid narration tests are designed and priced first (`narration-trial` dry run with `--check-balance`) and run only after the user's explicit yes; the 2026-11-20 plan budgeted about 3,000-4,000 credits. Related: [[create-video-adaptive-niche-guardrail]], [[awl-elevenlabs-v4-no-edit]], [[scripts-gather-agents-decide]], [[wpm-calibrate-from-transcripts]].

**2026-11-22 (brief #4, Garbo v2), measured:** a pause cue may carry part of a whole silence and the edit tops up only what its measured pause leaves (`pause_via: edit` with the cue around it in the `pause_total_s` form = a residual; the older added-on-top form stays refused); before the line is recorded the planned hold subtracts the cue's expected time, counted once. On George/eleven_v4, delivery cues barely move the speech rate: the re-recorded climax with [quietly] and [short pause] went 177 -> 175 wpm; [quietly] -3.3 dB, [softly] -2.4 to -9.5 dB, [short pause] inside a line 0.6-0.8 s, [pause] inside a line 1.2-1.4 s. Pace comes from the writing, performed pauses and the decided holds, never a speed control. Billing exactly as forecast: 0.4 credits per character sent (cost headers), the live balance lags a few minutes.
