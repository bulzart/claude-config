The user's brief "Workflow-Wide Storytelling Intelligence" (2026-11-24), built into static-studio on 2026-11-25
(commit 723552b, tag static-studio-storytelling-1, local only, never pushed):

- Promise and delivery: what the opening promises, where it is first delivered, and whether each wait builds
  anticipation or only delays. No fixed minute or percentage for a payoff; a long build that rewards is a choice.
- A major problem that two independent readers find means the earlier revision missed its cause: answer it with the
  root cause (order, structure, treatment, material, duration), never rewording; a structural cause is re-planned
  (direction-lock --revise), a duration cause goes to the user. A higher reader score never closes a major.
- A harmless format slip in a reader's file is normalized, words untouched and the original kept; never re-run a
  reader for it.
- Significance stays authentic: two things linked by place are told as that link, never as cause or foresight.
  What a key moment leans on is planted where it first appears and re-anchored at the moment; pictures reinforce
  words, never rescue them.
- Runtime: a cohort shares the niche, not necessarily the format (decision.length_fit). Never inflate the script to
  fill the lock and never move the lock silently: a mismatch goes to the user with the evidence.
- Pace follows the treatment's narrator, not the length cohort: the Qin run's 202 wpm came from fast second-person
  WW2 narrators and forecast the script 20% short; the niche's calm documentary narrator (V007) measured 163, and the
  real eleven_v4 voice of the earlier run 164 (line gaps ~0.6 s). On the user's authorisation (2026-11-25) the run was
  re-locked as an own length, 16:30, from the strongest script at V007's pace (`length --revise --user-approved`).
- Research to script: select what the viewer needs at that moment; scale and numbers only from read sources.

**Why:** in the Qin letters run both script readers found the letters arriving ~40% in; draft 3 only trimmed, and the
climax implied the empire "broke" where the letters came from. The process had let rewording answer a structural
problem.

**How to apply:** diagnose the cause before any fix; re-plan the treatment when the cause is structural; report a
length mismatch with evidence instead of padding. Related: [[create-video-significance]],
