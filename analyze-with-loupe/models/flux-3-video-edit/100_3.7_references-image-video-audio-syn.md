### 3.7 References (image / video / audio): syntax, roles, what is inherited and what must be excluded

No image, style-video or audio inputs [OFFICIAL]. The single video is the edit source. Everything is inherited except what the prompt changes. Overlays, usernames and watermarks are therefore inherited unless named (§3.11d).
- **Placement preview (Recreate and Edit Mode, every placed product; `reference/generation-system.md` §4b.6):** no input rides beside the single edit source (form c): the source is the unmarked original, and the spot and size ride in words only (the anchor sentence with the size reckoning); the plan takes an anchor from the passing list or writes the size risk in the brief. The marked copy is never the edit source.
