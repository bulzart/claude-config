# Tests of the /analyze-with-loupe library

`python tests/run_all.py` runs the three scratch suites (about 100 checks, two to three minutes); `python tests/run_all.py --real` adds the real-data suite. `python scripts/check_all.py` (or `scripts/check-all.cmd` / `.ps1` / `.sh`) runs them with the docs check and Loupe's own tests and prints one table. Every suite calls the toolkit through its command line; the runs it creates live in a temp library copy (`AWL_HOME`), so nothing under the real `runs/` is touched. Set `AWL_UNDER_TEST=<path to a working copy of awl.py>` to test a copy before swapping it in.

| suite | covers |
|---|---|
| `t01_library` | the structure, without a model call or a run: `docs_tool.py check` reports 0 errors; the router names all 19 phase skills; the router and the skills are LF with complete frontmatter; every hand-off names an existing skill and every `AWL/` path a Read-now list names exists; every `T <command>` in the router, the skills and the references is a command of `awl.py`; the Loupe wiring (run creation, resume, before spawning, the contract line, state.json `loupe`, qc-consult once per video, needs_unmet and --note, plan-hints, caught-flag add and reconcile); the audio question (awl-start step 5b, item 24, the contract line, the card wording); the retired ledger, the obsolete learning command and the other pipeline appear nowhere (the names are built in pieces inside the test) |
| `t02_toolkit` | the toolkit on scratch fixtures (synthetic clips with a white flash, a hand-made text PDF, an image-only PDF): run resolution (full path, bare name, stamp prefix, an ambiguous prefix refused, a missing name refused); PDF extraction and the image-only flag; the asset inventory without file-name hints; `prep-all` refusing without `audio_ingest`, frames-only (no transcript, "audio not ingested") and whisper (a stub engine, no model loaded); `prep-video --audio-ingest`; `strip-inserts` and `seams` (the flash shows as a luma ramp); `status`, `cost-report`, `lint-run`, `doctor` as gather-only reports |
| `t03_loupe` | the Loupe coupling against a Loupe server started in the test process on a temp data folder, the keeper replaced by a fake: `loupe ensure` (library size, keeper state, the bounded wait that reports `syncing`, the consult that then meets the booted keeper once), `qc-brief`, `qc-consult` (the saved answer, `needs_unmet` with its rule, a second ask with `--note`), `plan-hints` (saved hints), `ledger set --flagged`, `caught-flag add`, `set`, `reconcile` and `list` |
| `t04_real` (opt-in) | real data, read-only on the sources: the user's reference folder (`AWL_TEST_REFS`), a real guardrails PDF (`AWL_TEST_PDF`), the real V10 original's flash at 7.52 s, one real clip through faster-whisper in both modes, the real Loupe library through `qc-brief` (no model call); with `AWL_TEST_LIVE_KEEPER=1` one real `qc-consult` and one real `plan-hints` (a few cents) |

The rule behind them (the user, 2026-10-12): a script gathers, extracts, records, tabulates or calculates and never evaluates; the agent that runs the pipeline decides. A new command comes with a check that it returns numbers, tables or records and no verdict.
