#### 5c.2b Prepare the source (before it rides as the video reference)
The model keeps what the source holds, so what must not survive is changed in the prepared copy, not only in
the prompt. The analysis card flags each (`analysis-protocol.md` §3, "Source preparation flags").
- **Orientation: never flipped.** The output keeps the original's perspective (the user, 2026-10-27: "video should be in the original
  perspective not reverted/mirrored"). A source is never flipped, in any mode, not even a front-camera selfie shown un-flipped (reversed
  shirt print, a left-handed guitar, reversed signs): its own print and signs stay as the original shows them, while the client's product
  label reads correctly (`anomaly-catalog.md` §2.9). The prompt says "Video 1's orientation stays exactly as it is; nothing is flipped;
  the <product> label reads left to right". Only an identity photo that is itself a mirrored selfie is turned to the person's true face
  (read its lettering first): it is a face reference, not the video. (CE-030's flip of the source, made on the client's word "maybe
  flip video, then add bag", is retired by this rule: the frame keeps the original's reversed print beside a correctly read label.)
- **Burned-in text on a flat surface** (a caption on a wall) is never removed by a tool (no inpaint, delogo or
  crop in Analyze Mode). The clean-plate lines are the highest-priority lines of the prompt and are never
  trimmed: with them cut, the model handed a garbled grey ghost of the caption to the take at the same place
  (CE-045; gone on the retry that restored them).
- **Names and marks that identify** (a real person's name in a chat bubble, a patch or logo on the kept
  garment): written as an edit of the source surface in the model's edit grammar (§8, `brand-guardrails.md` §4). A one-sentence edit changed a
  name in one shot only and left it legible in two others (CE-080); a patch named only in the negatives came
  back from 0.4 s (CE-065).
- **A placed product** (Recreate and Edit Mode, where the plan places one): nothing is composited into the
  prepared copy. The original reference (§4b.5: the silent, unmarked footage) is the only video reference, the
  spot and the size are the prompt's, and no guide image is cut from a source frame.
- **A face effect baked into the video reference** (a mask, a filter, a clone) is carried whatever the prompt
  says about identity: plan a lever up front (hide it in the prepared source) or accept it flagged (CE-051).
