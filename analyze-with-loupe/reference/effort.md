# Effort level (contract item 33): how densely a run samples and inspects, and what never changes

The user picks the run's effort level at the start, in both modes (`awl-start` step 5d). It sets how densely the references are sampled
at analysis, how many production agents run at once and from how many videos the pilot runs first. `T effort` stores it in
`state.json → effort`; `T prep-all` reads the sampling and the produce phase the pacing, so no step passes rates by hand. One budget is
the analysts' to keep: the densified ranges per reference (`analysis-protocol.md` §1). QC and Loupe are never part of it: the judges
stay stable (§2).
