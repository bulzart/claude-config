# Viral-Browser — read what made the references spread, then find the next three products to sell with the same approach

Analyze Mode's third sub-mode (skills `atg-vb-*`, steps V1–V9). **The references folder is a source of ideas**, not material to edit (Recreate) or to imitate (Create). The run learns *why* the videos spread, then looks across the whole market, not only inside the references' niche, for the products that could spread the same way, researches them, and hands back **three data-backed picks**, each with a viral blueprint (the engagement style combined with what is trending now) and a **reference pack**: the product's sourced specification (size, weight, material, texture, usage, …) and links to photos from several angles, with nothing downloaded (§9.1).

**Nothing is generated:** no model is picked, no Higgsfield generation tool is called, no credits are spent, no CapCut project is written, no client assets are asked for. The run reads, measures, searches and reasons, and writes files.

Load this with `analysis-protocol.md` (§0 provenance, §1–§2 how to read a video, §4 lenses, §7 scale and delegation), `creative-direction.md` (§1 roles, §3 audience model, §4 trend read, §5.0 craft versus subject) and, only at the continuation to Create (§11), `anomaly-catalog.md`.

Two things this mode must never do: **let the references' product niche decide the answer** (§5), and **state a number it did not get from a source or a method** (§0).

**Scripts gather, agents decide (user, 2026-10-12).** The Python toolkit (`T`, `atg.py`) only gathers, extracts, records, tabulates and calculates (it measures videos, extracts frames, transcripts and on-screen text with their numbers, probes a link with a header request, keeps the agents' facts and decisions in ledgers with who, when and why, sorts and counts on request, and does pure arithmetic). It never evaluates: no verdict, status, flag or label derived from content, no threshold that refuses, caps or changes an answer, no ranking, no tie-break, no comparison of texts or names, no word counting to decide anything. Every judgement in this document is made by the AI agent the sentence names (the main session, the fresh niche-audit agent, the blind scoring agent, the red-team agent, the research agents, the reference-pack agents) and is recorded with its reason (`--by`, `--reason`, the bias log in `30-research/ranking.md`). The numbers that bound a choice (pool shares, the dominance threshold, evidence caps, rating floors, tolerances, minimum angles) are **rules of thumb**: they live in `config.json → viral_browser.rules_of_thumb` (read its `how_to_read`), no script reads them, and the agent applies each with judgement, may depart from it when the evidence says so, and writes down what it applied or set aside and why. The commands still refuse a bad argument, a missing file, a damaged ledger or an unsafe web address (form and safety, never content).

The same mining runs inside **Create** (§14): there it is applied to the client's own product (the supplied assets) instead of a product search.
