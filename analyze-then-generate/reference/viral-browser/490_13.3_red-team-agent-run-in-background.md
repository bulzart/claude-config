Never invent evidence, a URL or a quote; pages you cannot read go in your queue file as `- <lane> | <URL> | <what to read>`; if you find nothing against a candidate, say so.
Final message: one line per candidate: reading, the strongest counter-evidence id, the criteria to revisit. Then a short list of pipeline problems you met (a tool that failed, a flag or instruction that did not match, a place where the instructions were unclear).
