A `blocked` or `unchecked` link is kept as unconfirmed (do not retry it or look for another route to the same image); for a `dead`, `not-image` or `format` answer you reject the link yourself with `T photo set --run <RUN> --id PH### --reject --reason "…"` (nothing is rejected for you). Use one spelling per view (the table does not fold `rear` into `back`). Prefer https addresses and the larger version of an image (the one the page gives for zoom).
